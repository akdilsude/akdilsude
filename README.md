### 🧠 Featured Projects

* 🎮 **[cub3D](https://github.com/akdilsude/cub3D)**: A 3D game engine inspired by Wolfenstein 3D. Built entirely in C using the MiniLibX graphics library and mathematical Raycasting algorithms.
* 🐚 **[minishell](https://github.com/akdilsude/minishell)**: Re-creation of a minimal bash shell focusing on process management (fork, execve), pipes, file redirections, and custom signal handling.
* 🍝 **[philosophers](https://github.com/akdilsude/philosophers)**: Solution to the Dining Philosophers problem focusing on multithreading, mutexes, semaphores, and preventing race conditions/deadlocks.
* 🗣️ **[minitalk](https://github.com/akdilsude/minitalk)**: Client-Server communication protocol built using UNIX signals (`SIGUSR1` & `SIGUSR2`).
* 🗺️ **[so_long](https://github.com/akdilsude/so_long)**: 2D top-down game focusing on MiniLibX graphics, event handling, and pathfinding validation.
* 📊 **[push_swap](https://github.com/akdilsude/push_swap)**: Optimized stack sorting algorithm using a limited set of instructions and minimal operations.
* 🌐 **NetPractice**: Deep dive into networking, configuring IP addressing, subnetting, and routing protocols.
* 🧩 **C++ Modules (00-09)**: A comprehensive journey into Object-Oriented Programming, covering Orthodox Canonical Form, polymorphism, templates, and STL containers.
* 📚 **[libft](https://github.com/akdilsude/libft)**: Re-creation of C standard library functions (`malloc`, `string` manipulation, linked lists).
